# Bookstore API

A simple RESTful API built with Node.js and Express.js for setting up and understanding backend development fundamentals.

## Features

- **GET /** - Welcome message and API overview.
- **GET /api/health** - Server health check endpoint (`{ "status": "ok" }`).
- **GET /api/books** - Retrieves a hard-coded list of books in JSON format.

## Technologies Used

- **Node.js** - JavaScript runtime engine
- **Express.js** - Web framework for backend routing
- **Nodemon** - Development tool for auto-restarting the server
